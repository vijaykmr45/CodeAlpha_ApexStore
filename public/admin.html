🎨 How to Create & Use Icons in ApexStore

ApexStore uses clean, scalable **vector SVG (Scalable Vector Graphics)** icons and emoji badges. SVGs are lightweight, render crisply on retina displays, and can be colored dynamically with CSS currentColor or custom fill/stroke properties.

1. Standard SVG Icon Template

<svg width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">
  <!-- Paths go here -->
</svg>

3. Free Online Sources to Create or Download New SVG Icons

  • Lucide Icons: 1000+ clean open-source SVGs. Just search an icon and copy its SVG code.
  • Heroicons: Modern icons created by the Tailwind team.
  • SVGOMG: Paste raw SVG code to minify and optimize size.
